### 7. Simplify `embed_fn` Closure Pattern
**Location:** `assistant/backend/pipeline/orchestrator.py:166-177`
**Issue:** `_embed_fn()` returns new closure; `embed_fn()` calls it creating nested closures.
**Fix:** Single method returning callable:
```python
def embed_fn(self) -> Callable[[str], Awaitable[list[float]]]:
    async def get_embedding(text: str) -> list[float]:
        resp = await self.llm_client.embed(text)
        return resp.embedding
    return get_embedding
```
